# NutriTrack Pro

A modern nutrition tracking dashboard



## 🌟 Features

* **Interactive Dashboard:** Real-time tracking for calories, protein, carbs, fats, and water intake.
* **Smart Fridge Generator:** Input leftover ingredients to instantly match them to classic recipes scaled to your remaining macros.
* **AI Coach & Slip-up Recovery:** Dynamic guidance cards and automated weekly calorie adjustment tools.
* **Weekly Planner & Grocery List:** Integrated meal planning that automatically compiles your weekly shopping list categorized by grocery aisle.
* **Advanced Analytics:** Long-term trend tracking for weight, calorie consistency, and micronutrient matrices.

## 🛠️ Tech Stack

* **HTML5 / CSS3**
* **Tailwind CSS** (via CDN for rapid, clean styling)
* **JavaScript** (Vanilla / Interactive UI states)
